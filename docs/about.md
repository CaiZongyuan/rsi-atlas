# 关于

一个关于**递归自我改进（Recursive Self-Improvement, RSI）**的独立阅读站：逐个收录相关工作，用论文、源码、运行轨迹三种证据交叉核对。

## 是什么

- 一个**读书笔记 + 核对工具**：每篇都尽量读到代码与运行记录，而不只是摘要。
- 一个**横向对比**的框架：按「改什么 / 判断信号 / 递归层级 / 可复现性」四条轴摆放。
- 一个**可以自己翻**的档案：RSIGym 的 18 条轨迹做成了浏览器，可以逐步查看。

## 不是什么

- 不是论文的官方文档，也不代表原作者观点。
- 不是排行榜。不同论文的基准、预算、评测协议都不同，跨行比分数没有意义。
- 不是“RSI 综述”。收录的是我实际读过并做过核验的工作，覆盖必然不全。
